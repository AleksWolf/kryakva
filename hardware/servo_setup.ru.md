# Сервы: ID и ноль

До сборки, по одной серве. Понадобятся UC-01 (по USB-C к компьютеру), питание 7.4 В в клеммник UC-01, напечатанная пластина
[cad/calibration_plate.step](../cad/calibration_plate.step) и пульт серв [software/servo_console](../software/servo_console/README.ru.md).

## ID серв

| Серва | ID |
|---|---|
| правая нога: рыскание, крен, тангаж бедра, колено, голеностоп | 10, 11, 12, 13, 14 |
| левая нога: то же | 20, 21, 22, 23, 24 |
| тангаж шеи, тангаж головы, рыскание головы, крен головы, клюв | 30, 31, 32, 33, 34 |

## Порядок

Новая серва отвечает с ID 1, поэтому подключаются по одной: выключить питание, подключить серву, включить питание.

Из папки [software/servo_console](../software/servo_console/README.ru.md):

```
python new_servo.py check       # серва найдена, заводские регистры в норме
python new_servo.py setid N     # N — ID из таблицы
python new_servo.py center N    # вал в середину (2048), момент снят
python new_servo.py save N      # сохранить ноль
```

Порт по умолчанию COM3, другой — `--port COMx`.

Между `center` и `save` выровнять качалку по калибровочной пластине. После `save` подписать на серве её ID.

Прочитать регистры всех серв на шине, ничего не записывая: `python servo_report.py --port COMx`.

## Регистры

Заводские P/D (32/40) в EEPROM не меняются. Политики работают с P = 5, D = 0 в ОЗУ серв ([training/policies](../training/policies/README.ru.md)).
Защита по току с завода выключена, по перегреву (80 °C) — включена.

## Качалки

Задние пассивные качалки снимаются у серв 10–14, 20–24, 32, 33, 34. У серв 30 и 31 задние диски остаются.
