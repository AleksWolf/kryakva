# Страница утки

Страница состояния и управления на самой утке: `http://<адрес Zero>:8082`. Работает поверх программы робота (`robotd`):
сервы и IMU читает через неё, шину серв сама не трогает.

Показывает: напряжение батареи, сервы (положение, температура, ошибки), IMU, дальность ToF, проверку камеры, температуру процессора,
3D-модель утки в текущей позе, журнал.

Кнопки: «Подъём» — включить политику (утка встаёт); «Relax» — снять момент (стоящая утка упадёт); джойстик — скорость и поворот, пока страница шлёт кадры (нет кадра 350 мс — стоп);
пока подключён DualSense, джойстик страницы выключен; «Выключить» — снять момент и выключить Zero;
переключатели камеры и ToF.

Язык страницы — английский или русский, переключатель EN | RU вверху; выбор запоминается в браузере.

## Установка

Нужны robotd из [настройки Zero](../zero_setup.ru.md) (раздел 4) и `tof_check` из `/home/duck/zero` (раздел 1).

Папку `software/duck_page` скопировать на плату в `/home/duck/duck_page` и поставить службу:

```
cd /home/duck/duck_page
sudo cp duckpage.service /etc/systemd/system/ && sudo systemctl enable --now duckpage
```

Пишет только в журнал systemd.
